# 手势指挥家

PICO Project Swan 的音乐游戏。玩家站在音乐厅的指挥台上，指向一个声部捏住让它进入，抬手或压手带动它的音量，松手让它收尾。每首曲子由多轨合奏组成，每个声部是一轨独立的音频，由玩家的手势带进来。

- 演出逻辑：`app/app/src/main/java/com/vrgames/conductor/core/Performance.kt`，纯逻辑，不依赖引擎。
- 曲目数据：同目录 `Pieces.kt`，由 `tools/make_scores.py` 生成，同时生成各声部音频。
- 混音：`render/Mixer.kt`，MediaCodec 解码，AudioTrack 混音。
- 测试钩子：调试包里 `adb shell am broadcast -a com.vrgames.conductor.TEST -p com.vrgames.conductor --es cmd walk`，说明见 `game/AutoPilot.kt`。

## 曲目
茉莉花、欢乐颂、小夜曲、蓝色多瑙河、自新大陆广板、斗牛士之歌、康定情歌、送别。

全部是公有领域的旋律，由 `tools/make_scores.py` 编配，FluidSynth 和 FluidR3_GM 音色库（MIT 许可）合成。**合成的音频还没有人听过，要在真机上确认。**

设计方案上原来写的是《梅花三弄》和《高山流水》。这两首我凭记忆写不准，换成了《康定情歌》和《送别》。

## 素材
- 模型、贴图和全景图：火山方舟 Seedream 和 Seed3D 生成。
- 旁白：ListenHub 语音合成。
- 音效：`tools/sfx_synth.py` 合成。
